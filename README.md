# Task 1 - Sign Up Flow

## Project Overview
This project is a clean and user-friendly Sign Up Flow designed using Figma. The goal was to create a simple and intuitive registration experience with a modern interface.

## Features
- Clean and minimal design
- Easy-to-use interface
- Mobile-friendly layout
- Simple navigation
- Consistent color palette and typography

## Tools Used
- Figma

## Deliverables
- UI Design
- Prototype
- Screenshot
- Demo Video
